# Implementation Notes

Use this folder for documentation about what the app currently does and how it is implemented. These are not phase plans or reusable context briefs; they capture the concrete shape of the current build.

## Examples
- `rosary-and-speech-implementation.md`
- `prayer-data-and-store-implementation.md`

## Conventions
- Keep each doc focused on a single implementation area.
- Prefer short, linkable files over long multi-topic documents.
- Start each file with a one-line purpose statement.
- Use `implementation-note-template.md` as a scaffold for new docs.
